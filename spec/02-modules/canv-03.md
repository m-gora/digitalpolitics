# Template Forking
It should be possible to copy campaigns as a template.

Forking copies the canvas field answers (Zieldefinition, Zielgruppen & Kanäle, Material, Organisation & Storytelling) only, into a new campaign in `Draft` status (see canv-05). Hierarchy placement, initiative membership, and any collected feedback data are **not** copied; the user forking the campaign must assign these themselves.

Since read access is global (arch-02), any campaign — including `Finished` and `Archived` ones — can be forked regardless of which district produced it.
